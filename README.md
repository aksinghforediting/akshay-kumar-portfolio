# Akshay Kumar — Portfolio

A responsive single-page portfolio built with HTML, CSS, and JavaScript.

## Preview locally

From this folder, run:

```powershell
py -m http.server 8000
```

Open http://localhost:8000 in a browser. Stop the server with Ctrl+C.

## Site files

- `index.html` — portfolio content
- `style.css` — responsive styles
- `script.js` — mobile navigation and automatic footer year
- `Oct 2026 Professional Resume (1).pdf` — CV download
- `WhatsApp Image 2024-08-04 at 6.43.45 PM.jpeg` — profile photo
- `assets/` — design images used in the creative gallery

The Git ignore rules allow only site files and assets referenced by the page, avoiding unrelated files in the public repository.

## GitHub Pages

Create a public repository named `akshay-kumar-portfolio` under `aksinghforediting`. Push the `main` branch, then select **Settings → Pages → Deploy from a branch → main → /(root)**. The expected project-site URL is:

https://aksinghforediting.github.io/akshay-kumar-portfolio/
